## 1. 제안 한 장 요약

**VECTA Stock은 국내주식(KOSPI·KOSDAQ 약 2,500여 종목)을 매 거래일 자동으로 계산해,
"살 값 · 나올 값 · 비중"이 적힌 실행 계획과 리포트를 발행하는 엔진과 서비스입니다.**

제휴로 드릴 수 있는 것은 셋 중 하나 이상입니다.

| | 제공 | 상대가 얻는 것 |
|---|---|---|
| **A. 콘텐츠 공급** | 매일 생산되는 브리프·리포트·시황을 귀사 채널에 | 사람 손 없이 **매일 채워지는 국내주식 콘텐츠** |
| **B. 전문가 파트너** | 검증된 전문가에게 필명 코너와 독자 | 데이터 없이도 **엔진 근거 위에서 쓰는 글** |
| **C. 엔진 · 데이터 연동** | 팩터·밸류에이션·시그널·백테스트 결과를 API로 | 자체 퀀트 조직 없이 **분석 레이어 확보** |

**공통 전제 세 가지 — 이것을 지키는 조건에서만 제휴합니다.**
1. 수익을 보장하는 표현을 쓰지 않습니다
2. 숫자는 코드가 계산하고 AI는 서술만 합니다 (환각 차단)
3. 실패한 기록을 지우지 않습니다

## 2. 우리가 가진 것

### 2-1. 매일 도는 분석 엔진 (운영 중)

```
08:30  해외 지수·환율 갱신 → 모닝 브리프
16:30  수집 → 신선도 가드 → 가격 보정 → 분석 → 백테스트 게이트
       → 시그널·레벨 산출 → 리포트 → 오늘의 픽 선정
```

- **데이터 소스**: KIS(시세·수급) · DART(재무·공시) · FRED(매크로) · 뉴스
- **분석 축**: 멀티팩터 · 밸류에이션 · 수급 · 마이크로구조 · 국면(레짐) · 리스크
- **셋업 20여 종**: 돌파 · 눌림목 · 과대낙폭 반등 · 쌍바닥 · 52주 신고가 · 변동성 수축 돌파 · 실적 모멘텀(PEAD) · 수급 동반 매집 등
- **보유 기간 축**: 단기(5거래일) · 중기(10거래일) · 장기(20거래일)

### 2-2. 매일 생산되는 콘텐츠

| 산출물 | 주기 | 성격 |
|---|---|---|
| 모닝 브리프 | 매 거래일 | 장 시작 전 국면·해외 변수 요약 |
| 오늘의 픽 | 매 거래일 | 진입·손절·비중이 붙은 실행 계획 |
| 기업 분석 리포트 | 매 거래일 | 5축 진단 + 밸류에이션 + 근거 |
| 주간 브리핑 | 주 1회 | 한 주 정리 |
| 블로그 「데이터」 | 자동 | 엔진이 직접 씁니다 (사람 글과 물리적으로 분리) |

### 2-3. 검증 인프라 (여기가 핵심 자산입니다)

발행 전에 통과해야 하는 게이트입니다. **통과 못 하면 발행하지 않습니다.**

| 항목 | 기준 |
|---|---|
| 최소 표본 | 20건 이상 |
| 기대값 | 거래비용(수수료·세금·슬리피지) **차감 후** 양(+) |
| 최대낙폭 | 일별 리스크 예산 곡선 기준 상한 |
| 이상치 | ±10R 윈저라이즈 — 대박 몇 건이 평균을 뒤집지 못하게 |
| 워크포워드 | 기간 4등분, 과반 구간에서 양(+) |
| 최근 구간 | 최근 구간 기대값이 음수면 탈락 |
| 진입 가정 | 실제 발행과 동일한 **다음 거래일 시가 시장가** |

> 이 게이트 때문에 **장기(20일) 픽은 현재 발행을 쉬고 있습니다.**
> 성적이 떨어진 전략을 스스로 끄는 것이 이 엔진의 정상 동작이고, 제휴 파트너에게 드리는 신뢰의 근거입니다.

### 2-4. 서비스 (운영 중)
Next.js 15 웹(Vercel) · Supabase(서울) 회원·인증 · 8개 메뉴 · 모바일 대응 · 전문가 코너 · 성과 추적.

> 회원 수·트래픽 등 운영 지표는 **NDA 후 협의 자리에서 공유**드립니다.

## 3. 제휴 모델

### 모델 A — 콘텐츠 공급 · 신디케이션

**대상**: 증권·핀테크 앱, 미디어, 뉴스레터, 커뮤니티

**형태**
- 모닝 브리프 / 주간 브리핑 / 기업 분석을 귀사 채널에 정기 공급
- 귀사 톤·분량에 맞춘 포맷 조정 (엔진 출력을 바꾸는 것이 아니라 표현 계층만)
- 출처 표기 + 원문 링크백

**드리는 것** — 사람 손 없이 매일 채워지는 국내주식 콘텐츠. 휴가도 슬럼프도 없습니다.
**받는 것** — 유입 채널과 브랜드 노출.
**준비 기간** — 2~4주 (포맷 협의 + 전달 방식 구축).

---

### 모델 B — 전문가 파트너 (지금 바로 가능)

**대상**: 애널리스트 출신, 검증된 트레이더, 투자 크리에이터

**형태**
- 「인사이트 · 전문가 추천」에 **필명 코너**를 드립니다
- 엔진의 분석·차트·리포트를 **근거 자료로 자유롭게 인용** 가능
- **전문가 글은 엔진 픽과 섞이지 않습니다.** 코너가 물리적으로 분리되고 필명이 함께 공개됩니다

**드리는 것** — 데이터 작업 없이 글에만 집중할 수 있는 근거 인프라와 독자.
**받는 것** — 기계가 못 쓰는 맥락과 서사. 콘텐츠 다양성.
**절차** — 가입 → 전문가 참여 신청(필명·참여 이유) → 운영자 검토 → 승인 → 집필.
**준비 기간** — 즉시. 이미 운영 중입니다.

> ⚠️ 유료 추천·구독 형태의 전문가 코너로 확장할 경우, **유사투자자문업 신고 완료 후**에 진행합니다.

---

### 모델 C — 엔진 · 데이터 연동 (API / 화이트라벨)

**대상**: 자체 앱을 가진 증권·핀테크사, HTS/MTS 부가 서비스, 로보어드바이저

**공급 가능 단위**

| 단위 | 내용 |
|---|---|
| 팩터·밸류에이션 스코어 | 종목별 5축(밸류·성장·수급·모멘텀·안정성) + 적정가 |
| 시그널·가격 레벨 | 셋업·기간별 진입·손절·목표 + 손익비 |
| 백테스트 성적 | 조합별 승률·손익비·기대값·최대낙폭·워크포워드 |
| 포트폴리오 진단 | 가중 베타·변동성·섹터 집중도·합성알파 |
| 시황·리포트 텍스트 | 브리프·리포트 본문 |

**드리는 것** — 퀀트 조직을 새로 만들지 않고 분석 레이어를 붙이는 길.
**받는 것** — 유통 채널, 그리고 실사용 규모에서만 나오는 피드백.
**필요한 것** — 상호 데이터 라이선스 확인(원천 데이터 재배포 범위), 인증·SLA·정산 구조 설계.
**준비 기간** — 6~10주 (현재 내부 조회용 구조 → 외부 API 계층 신설 필요).

> 솔직하게: **외부 공개 API는 아직 없습니다.** 데이터와 계산은 전부 있고, 외부에 내보내는 계층을 만들면 됩니다. 파트너가 정해지면 그 요구에 맞춰 설계하는 편이 낫다고 봅니다.

## 4. 왜 우리와 하나

**1. 콘텐츠가 사람에 묶여 있지 않습니다.**
필자가 쉬어도 매 거래일 나옵니다.

**2. 틀린 것을 지우지 않습니다.**
성과 화면에 손절·만료·규칙 교체가 전부 남습니다. 제휴사가 가장 두려워하는 것은 **나중에 터지는 과장**인데, 우리는 과장할 구조를 갖고 있지 않습니다.

**3. 숫자와 서술이 분리돼 있습니다.**
AI가 수치를 지어낼 자리가 없습니다. 모든 값은 DB 근거로 추적됩니다. — 규제·평판 리스크를 구조로 낮춥니다.

**4. 안 되는 전략은 스스로 끕니다.**
장기 픽 발행 중단이 그 증거입니다. 성적이 죽은 전략을 계속 파는 서비스가 아닙니다.

## 6. 진행 절차

```
1주차   소개 미팅 — 모델 A/B/C 중 방향 결정
2주차   NDA → 운영 지표·샘플 산출물 공유
3~4주차 파일럿 범위 확정 (공급 항목·주기·표기·정산)
5주차~  파일럿 운영 (4~8주) → 지표 리뷰 → 본계약
```

**파일럿을 먼저 하자고 제안드립니다.** 계약서보다 실제 산출물이 판단에 낫습니다.

## 7. 협의가 필요한 열린 항목

숨기지 않고 먼저 적습니다.

- **정산 모델** — 정액 / 트래픽 연동 / 레버뉴 셰어 중 미정
- **독점 여부** — 업종 내 독점 공급을 원하시면 조건 협의 필요
- **외부 API** — 미구축. 파트너 요구사항에 맞춰 설계
- **원천 데이터 재배포** — 소스별 라이선스 확인 필요
- **유료 제휴 시점** — 유사투자자문업 신고 완료 이후
