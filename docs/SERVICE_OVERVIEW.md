## 1. 우리가 푸는 문제

개인투자자가 깨지는 이유는 **좋은 종목을 몰라서가 아닙니다.**

| | 개인 | 프로 |
|---|---|---|
| 진입 | 감·뉴스·테마 추격 | 검증된 패턴 |
| **청산** | **없음(존버)** 또는 뇌동매매 | **미리 정해 둔 손절·익절** |
| **비중** | 몰빵·물타기 | **계좌 대비 고정 리스크** |
| 맥락 | 무시 | 장 국면에 따라 무기 교체 |
| 근거 | "누가 좋다더라" | 숫자와 기록 |

정보는 이미 넘칩니다. 네이버·증권사 앱에 **재료**는 다 있습니다.
없는 것은 **"그래서 얼마에 사고 어디서 나오느냐"**는 한 줄입니다.

> **네이버·증권사가 재료를 준다면, 우리는 요리를 냅니다.**

## 2. 우리가 주는 것

### ① 오늘의 픽 — 실행 계획
매 거래일 마감 뒤, 조건을 통과한 종목만 발행합니다. 각 픽에는 이것이 붙습니다.

```
진입가       다음 거래일 시가 (예상 진입가로 미리 표시)
손절가       깨지면 전량 매도
본전 도달가   닿으면 손절선을 본전으로 올림
1주당 리스크  진입가 − 손절가
권장 비중     손절 시 계좌 손실이 1%가 되도록 역산
보유 기간     단기 5거래일 / 중기 10거래일
```

**통과한 게 없으면 0건입니다.** 매일 채워야 하는 할당량이 없습니다.

### ② 검증 성적을 픽마다 함께
"검증 통과" 배지 하나로 뭉개지 않습니다. 그 픽이 쓴 조합의
**승률 · 손익비 · 거래당 기대값 · 최대낙폭**을 카드에 그대로 적고,
*"10번 중 6번은 손실로 끝납니다"* 처럼 **불리한 쪽까지 사람 말로** 씁니다.

### ③ 종목 분석 — 5축 진단
밸류 · 성장 · 수급 · 모멘텀 · 안정성을 한 장의 스노우플레이크로.
판정은 **매수 / 중립 / 관망 / 거래 부적합** 넷.

### ④ 내 포트폴리오 리스크 진단
보유 종목과 비중을 넣으면 **가중 베타 · 예상 변동성 · 섹터 집중도 · 합성알파**를 재고
분산 보강, 손절 라인 점검 같은 처방을 냅니다. *입력 내용은 저장하지 않습니다.*

### ⑤ 매일 읽을 것
모닝 브리프(매 거래일) · 주간 브리핑 · 기업 분석 리포트 · 매크로 · 전문가 코너.
**시황은 "전망"이 아니라 "과거에 이런 조건에서 몇 %였다"는 빈도로 씁니다.**

### ⑥ 성과 — 틀린 것까지
발행한 픽의 최종 결과를 전부 남깁니다. 손절도, 만료도, 규칙이 바뀌어 우리가 닫은 픽도.
살 수 없었던 픽(미체결)은 **거래로 세지 않습니다.**

## 3. 어떻게 만드나 — 하루 두 번, 사람 손 없이

```
08:30 (장 시작 전)
  └ 밤사이 해외 지수·환율 갱신 → 모닝 브리프 발행

16:30 (장 마감 후)  ← 픽이 나오는 시각
  ├ 1. 데이터 수집     시세 · 수급 · 재무(DART) · 공시 · 뉴스 · 매크로(FRED)
  ├ 2. 신선도 가드     그날 종가가 안 들어왔으면 → 배치 중단 (낡은 값으로 발행 금지)
  ├ 3. 가격 보정       병합·감자로 생긴 가짜 등락 제거
  ├ 4. 분석           밸류에이션 · 멀티팩터 · 리스크 · 국면 판정
  ├ 5. 백테스트 게이트  조합별 성적 재계산 → 통과한 것만 발행 허용
  ├ 6. 시그널·레벨     ATR·지지저항으로 진입/손절/목표 산출
  ├ 7. 리포트          숫자는 코드가 계산, 서술만 AI가 작성
  └ 8. 오늘의 픽 선정   국면·예산·중복을 보고 최종 선별
```

대상: **KOSPI · KOSDAQ 전 종목(약 2,500여 종목)**

## 4. 왜 믿을 수 있나 — 네 가지 규칙

### 규칙 1. 숫자는 AI가 만들지 않는다
점수·진입가·손절가·비중은 **전부 코드가 계산**합니다.
AI는 그 값을 **설명만** 합니다. 새로 만들어 내지 않습니다.
모든 수치는 DB 근거를 달고 추적됩니다. — *환각이 끼어들 자리를 구조적으로 없앴습니다.*

### 규칙 2. 검증을 통과하지 못하면 발행하지 않는다
셋업 × 기간 조합마다 백테스트를 돌리고, 통과 못 하면 **그 조합은 발행 금지**입니다.

- **거래비용 차감 후** 기준 — 수수료·세금·슬리피지를 이미 뺀 값
- **이상치 제거(±10R)** — 비현실적 대박 몇 건이 평균을 뒤집지 못하게
- **워크포워드** — 기간을 4등분해 "한 시기에만 먹혔던 전략"을 걸러냄
- **최근 구간 하한** — 옛날엔 되던 전략이 지금 죽었으면 탈락
- **최소 표본 20건** — 우연을 성적으로 세지 않음

실제로 이 게이트 때문에 **장기(20일) 픽은 현재 발행을 쉬고 있습니다.**
잘 안 되면 끄는 것이 이 시스템의 정상 동작입니다.

### 규칙 3. 진입 방식을 실제와 똑같이 잰다
백테스트가 "신호 나온 가격에 무조건 샀다"고 가정하면 성적은 좋아지지만 실전에서 안 맞습니다.
갭 상승한 종목은 못 사고, 떨어지는 종목만 잡히기 때문입니다.

그래서 검증과 실제 발행을 **모두 「다음 거래일 시가 시장가」로 통일**했습니다.
13개 조합을 전부 비교해 이 방식만이 실전과 일치한다는 것을 확인하고 바꿨습니다.

### 규칙 4. 틀린 것을 지우지 않는다
성과 화면에는 손절·만료·규칙 교체 정리가 전부 남습니다.
**맞은 것만 골라 보여주는 화면은 만들지 않습니다.**

## 6. 요금

**현재 전 기능 무료입니다.** 회원 등급도, 결제도 없습니다.

유료화를 하게 되면 **미리 알리고, 이미 열려 있던 것을 뒤에서 잠그지 않습니다.**
유료 전환 시 계획된 경계는 다음과 같습니다.

| 무료 | 유료(예정) |
|---|---|
| 홈 요약 · 시장 대시보드 · 브리프 | 픽 전문 (근거·레벨·청산 시나리오) |
| 리포트 요약 | 리포트 전문 · 진단 무제한 · 알림 |

> 유료로 구체적 시그널을 발행하기 전에 **유사투자자문업 신고**를 완료할 계획입니다.
