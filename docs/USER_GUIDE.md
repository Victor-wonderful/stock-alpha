# VECTA Stock 사용자 가이드

> 이 문서는 **회원이 화면을 어떻게 쓰는가**를 설명합니다.
> 서비스가 무엇인지는 [SERVICE_OVERVIEW.md](SERVICE_OVERVIEW.md), 제휴 제안은 [PARTNERSHIP_PROPOSAL.md](PARTNERSHIP_PROPOSAL.md).
> 기준일 2026-08-25. 화면이 바뀌면 이 문서도 같이 고칩니다.

## 0. 3분 요약

VECTA Stock은 **"오늘 뭘, 얼마에 사고, 어디서 나올지"를 계산해서 숫자로 적어 두는 서비스**입니다.

- 매 거래일 **장 마감 뒤 16:30**(한국시간)에 엔진이 그날 종가로 전 종목을 다시 계산합니다.
- 조건을 통과한 종목만 **오늘의 픽**으로 올라옵니다. 통과한 게 없으면 **0건**입니다. 억지로 채우지 않습니다.
- 픽에는 **진입가 · 손절가 · 본전 도달가 · 권장 비중 · 보유 기간**이 함께 적힙니다.
- 그 픽이 어떻게 끝났는지는 **성과** 화면에 남습니다. **틀린 것도 지우지 않습니다.**

한 줄로: **감이 아니라 규칙으로 사고, 규칙대로 나오고, 그 결과를 전부 남깁니다.**

## 1. 시작하기

### 1-1. 가입

1. 오른쪽 위 **회원가입** → 닉네임 · 연락처 · 이메일 · 비밀번호 입력
2. 로그인은 **이메일**로 합니다 (별도 아이디 없음)
3. 다른 회원에게 보이는 것은 **닉네임뿐**입니다. 이메일은 화면에 나오지 않습니다

**가입비·이용료는 없습니다.** 회원 등급도 없습니다. 나중에 결제를 받게 되면 미리 알리고, 이미 열려 있던 것을 뒤에서 잠그지 않습니다.

### 1-2. 가입하면 무엇이 열리나

로그인 없이 볼 수 있는 것은 **홈 · FAQ · 이용약관 · 개인정보처리방침**뿐입니다.
나머지 7개 메뉴는 전부 회원 전용입니다.

| 메뉴 | 이 화면이 답하는 질문 |
|---|---|
| **홈** | 오늘 무슨 일이 있었나 (요약 상태판) |
| **오늘의 픽** | 그래서 뭘 사나 (진입·손절·비중이 적힌 실행 계획) |
| **스크리너** | 조건으로 직접 찾아보고 싶다 (탐색 도구) |
| **분석** | 이 종목 어때 (종목별 5축 진단·리포트) |
| **시장** | 지금 장이 어떤 상태인가 |
| **인사이트** | 읽을 것 (매일 브리프·주간 브리핑·전문가 글) |
| **성과** | 이 서비스가 잘하고 있나 (발행한 픽의 최종 성적) |
| **내 자산** | 내 조합은 괜찮나 (관심 종목·리스크 진단·알림) |

> 모바일에서는 상단 메뉴 대신 **화면 아래 탭바**로 이동합니다.

## 2. 하루 사용법

시간이 없는 분을 위한 최소 동선입니다.

```
아침 (1분)   홈 → 모닝 브리프 한 줄 + 진행 중인 픽 상태 확인
             ※ 08:30 배치가 밤사이 해외 변수를 갱신해 브리프를 씁니다

장중         할 일 없음. 픽의 진입은 "다음 거래일 시가"라 아침에 이미 끝났습니다

저녁 (3분)   오늘의 픽 → 새 픽이 있으면 카드 4칸을 위에서 아래로 읽기
             ※ 16:30 배치가 그날 종가로 계산해 발행합니다

주말 (5분)   내 자산 → 진단 탭에 보유 종목 입력 → 집중도·베타 점검
             성과 → 이번 주에 끝난 픽 확인
```

## 3. 오늘의 픽 — 카드 읽는 법 ★가장 중요

픽 카드는 **사기 전에 읽는 순서** 그대로 네 칸입니다. 위에서 아래로 그냥 읽으면 됩니다.

### ① 얼마에 사고 어디서 나오나

| 칸 | 뜻 |
|---|---|
| **진입가** | 다음 거래일 **시가**에 시장가로 삽니다. 발행 당일에는 「예상 진입가」로 표시됩니다 |
| **손절가** | 이 가격이 깨지면 **전량 매도**. 예외 없습니다 |
| **본전 도달가** | 이 가격에 닿으면 **파는 게 아니라, 손절선을 본전으로 올립니다** (아래 3-1 참고) |
| **1주당 리스크** | 진입가 − 손절가. 1주를 살 때 실제로 거는 돈입니다 |
| **권장 비중** | 손절에 걸렸을 때 계좌의 딱 **1%**만 잃도록 역산한 비중입니다 (기본값, 최대 25%) |

### ② 왜 이 종목인가

엔진이 이 종목을 고른 근거 문장입니다. 점수·팩터·수급·셋업 조건이 요약돼 있고,
**「근거 리포트 전체 보기」**로 원문 리포트까지 갈 수 있습니다.

### ③ 어떻게 사고 파나

**기간(보유 기간)에 따라 사는 방법이 다릅니다.**

| 기간 | 보유 | 사는 방법 |
|---|---|---|
| **단기** | 최대 5거래일 (약 1주) | 다음 거래일 시가에 **전량** 매수 |
| **중기** | 최대 10거래일 (약 2주) | 시가 50% + 하락(−1×ATR) 시 50% **분할 매수** |
| ~~장기~~ | 최대 20거래일 (약 1개월) | *현재 발행을 쉽니다 (아래 6장 참고)* |

파는 순서는 이렇습니다.

```
손절가 이탈       → 전량 매도 (무조건)
본전 도달가 터치  → 손절선을 본전으로 올리고 계속 보유
기간 만료         → 시장가 청산
```

### 3-1. ⚠️ 목표가는 "파는 신호"가 아닙니다

가장 많이 오해하는 부분입니다.

**옛 방식**은 목표가에 닿으면 전량 팔았습니다. 지금은 다릅니다 —
목표가(=본전 도달가)에 닿으면 **팔지 않고 손절선만 본전으로 올린 뒤 기간까지 들고 갑니다.**

왜 바꿨나: 12개 조합을 전부 비교했더니 **예외 없이** 이쪽이 나았습니다.
목표에서 팔면 크게 오를 종목의 이익을 스스로 잘라내기 때문입니다.
**파는 주체는 목표가가 아니라 기간입니다.**

### ④ 이 조합의 검증 성적

이 픽이 쓴 **(셋업 × 기간)** 조합의 과거 백테스트 성적입니다.

| 지표 | 읽는 법 |
|---|---|
| **승률** | 100번 중 몇 번 이겼나. **40% 안팎이 정상입니다** |
| **이기면 O배** | 이길 때 잃을 때보다 몇 배를 버나 (손익비) |
| **거래당 +O.OOR** | 한 번 거래할 때 평균 기대값. 1R = 1주당 리스크 |
| **최대낙폭** | 이 전략을 쭉 따라갔을 때 계좌가 가장 많이 줄어든 폭 |

카드는 이 숫자를 **사람 말로 한 번 더** 씁니다 —
*"10번 중 6번은 손실로 끝납니다. 대신 이길 때 2.3배 벌어서, 4,221원을 걸면 한 번당 평균 +1,180원이 남았습니다."*

> 승률이 낮은 것은 **결함이 아니라 설계**입니다. 승률을 억지로 올리면 이익 구간을 잘라내게 되고, 실측에서 오히려 돈을 잃었습니다.
> 이 숫자는 **수수료·세금·슬리피지를 이미 뺀** 값이고, **과거 데이터로 잰 값이며 미래 수익을 보장하지 않습니다.**

## 4. 나머지 화면

### 홈
오늘 무슨 일이 있었는지 한 장으로 봅니다 — 시장 지표, 모닝 브리프, 진행 중인 픽, 오늘 발행된 픽, 최근 분석, 주간 브리핑, 전문가 글, 주요 뉴스.
**홈은 요약본입니다.** 실행 계획은 「오늘의 픽」에 있습니다.

### 스크리너
발행 중인 **시그널 전체**를 셋업·기간·조건으로 걸러 찾습니다.
⚠️ **스크리너에 뜬다고 매수 추천이 아닙니다.** 여기는 탐색 도구이고, 추천은 「오늘의 픽」뿐입니다.

### 분석
종목을 검색해 **5축 스노우플레이크**와 리포트를 봅니다.

| 축 | 보는 것 |
|---|---|
| **밸류** | 지금 가격이 싼가 (적정가 대비) |
| **성장** | 매출·이익이 늘고 있나 |
| **수급** | 외국인·기관이 사고 있나 |
| **모멘텀** | 최근 주가 흐름이 강한가 |
| **안정성** | 재무가 튼튼한가, 변동이 심하지 않은가 |

점수가 낮은 축은 **주황색 점**으로 표시됩니다. 리포트 판정은 **매수 / 중립 / 관망 / 거래 부적합** 넷입니다.

### 시장
지수·환율·해외 지수, **국면(레짐)**, 섹터 흐름, 공시·이벤트를 봅니다.

국면은 세 가지입니다 — **강세장(Risk-On) · 중립 · 약세장(Risk-Off)**.
약세장에서는 픽 자체가 줄거나 0건이 됩니다. 화면이 비어 보이면 고장이 아니라 **엔진이 참고 있는 것**입니다.

### 인사이트
읽을 것이 모이는 곳입니다 — **전문가 추천 · 매일 브리프 · 주간 브리핑 · 최근 기업 분석 · 매크로** 순서.
「매일 브리프」는 매 거래일 쌓이고, 지난 것도 아카이브에서 다시 읽을 수 있습니다.

> **전문가 글은 엔진 픽과 섞이지 않습니다.** 별도 코너에 필명과 함께 놓입니다.
> 전문가로 참여하려면 가입 후 **전문가 참여 신청**에서 필명과 참여 이유를 보내면 운영자가 검토합니다.

### 성과
발행한 픽이 어떻게 끝났는지 전부 남는 곳입니다. 상태는 여섯 가지입니다.

| 상태 | 뜻 | 성적에 들어가나 |
|---|---|---|
| **진행중** | 아직 안 끝남 | — |
| **목표 도달** | 이익으로 종료 | ✅ |
| **손절** | 손실로 종료 | ✅ |
| **만료** | 기간이 끝나 청산 | ✅ |
| **미체결** | 진입가에 끝내 안 닿아 **살 수 없었던 픽** | ❌ *거래가 아님* |
| **규칙 교체 정리** | 규칙이 바뀌어 우리가 닫은 픽 | ✅ *숨기지 않음* |

> **승률 = 수익으로 끝난 거래 ÷ 끝난 거래.** 미체결은 분모에 들어가지 않습니다 — 살 수 없었던 것을 성적으로 세면 거짓말이 됩니다.

### 내 자산 (관심 · 진단 · 알림)

**관심 종목**
담아 둔 종목의 시세·최근 판정·픽 여부를 한 줄로 봅니다. 각 화면의 ★ 버튼으로 담습니다.

**리스크 진단**
보유 종목과 비중을 입력하면 조합 전체를 진단합니다. **입력 내용은 저장되지 않습니다.**

| 지표 | 읽는 법 |
|---|---|
| **가중 합성알파** | 시스템이 이 조합을 선호하는가 (+0.3σ 이상이면 선호 구간) |
| **가중 베타** | 시장보다 얼마나 흔들리나 (1.1 초과면 시장보다 큼) |
| **예상 변동성(연)** | 1년 기준 흔들림 폭 |
| **섹터 집중도** | 한 업종에 몰려 있나 (40% 미만이면 분산 양호) |

아래에 **분산 보강 · 베타 관리 · 손절 라인 점검 · 분석 공백** 같은 처방이 붙습니다.

**알림**
픽 발행 · 관심 종목 시그널 · 손절/목표 도달 · 모닝 브리프 · 주간 트랙레코드를 켜고 끕니다.
⚠️ **현재 설정 저장과 발송(텔레그램 등)은 준비 중입니다.** 지금은 화면 안 피드로만 확인됩니다.

## 5. 용어 사전

| 용어 | 쉬운 말 |
|---|---|
| **셋업** | 매수 이유의 종류. 「돌파」, 「눌림목」, 「과대낙폭 반등」, 「쌍바닥(W) 반등」, 「52주 신고가」 등 |
| **기간(호라이즌)** | 며칠 들고 갈지. 단기(5일)·중기(10일)·장기(20일) |
| **국면(레짐)** | 지금 장의 성격. 강세장 / 중립 / 약세장 |
| **1R** | 한 번 거래에 거는 돈 = 진입가 − 손절가 |
| **기대값(R)** | 한 번 거래할 때 평균 몇 R을 버나. +0.35R = 1만원 걸면 평균 3,500원 |
| **손익비(R:R)** | 이길 때 버는 폭 ÷ 질 때 잃는 폭 |
| **최대낙폭(MDD)** | 전략을 따라가는 동안 계좌가 가장 많이 줄어든 폭 |
| **ATR** | 이 종목이 하루에 보통 얼마나 움직이나. 손절 폭을 정하는 기준 |
| **워크포워드** | 성적이 특정 한 시기에만 나온 건 아닌지, 기간을 쪼개 다시 확인하는 검증 |
| **합성알파** | 여러 지표를 하나로 합친 점수. σ(시그마) 단위 |
| **거래 부적합** | 통과한 셋업이 없어 **지금은 살 이유가 없다**는 판정 (나쁜 회사라는 뜻이 아님) |

## 8. 자주 겪는 상황

**"오늘 픽이 0건인데요?"**
→ 고장이 아닙니다. 조건을 통과한 종목이 없거나 약세장이라 엔진이 참고 있는 것입니다.

**"발행됐는데 왜 안 샀다고 나오나요?"**
→ 진입은 **다음 거래일 시가**입니다. 발행 당일 밤에는 아직 사기 전 상태가 맞습니다.

**"화면 숫자가 어제와 다릅니다."**
→ 하루 두 번(08:30 / 16:30) 배치로만 바뀝니다. 그 사이 값은 최대 60초 캐시됩니다.

**"승률이 너무 낮은데요?"**
→ 정상입니다. 3-④와 5장을 봐 주세요. 이 시스템은 **승률이 아니라 기대값**으로 굴러갑니다.

**"목표가에 닿았는데 왜 안 팔았나요?"**
→ 3-1을 봐 주세요. 목표가는 파는 신호가 아니라 **손절을 본전으로 올리는 신호**입니다.

**"내 관심 종목이 비어 있어요."**
→ 각 화면의 ★ 버튼으로 담아야 채워집니다. 예시 데이터를 넣어 두지 않습니다.
